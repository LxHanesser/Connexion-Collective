# Connexion Collective 开篇：连接，从这里开始

欢迎来到 Connexion Collective。

如果你点开了这篇文章，说明你和我之间已经建立了一条小小的连接——而这，正是这个名字的全部意义。

## 为什么叫 Connexion Collective？

**Connexion**，是"连接"的法语拼写，也是英语 connection 的变体。选择它，是因为我想强调的不是冷冰冰的"链接"，而是人与人、想法与想法之间那种真实的、有温度的联结。

## 你会在这里看到什么？

内容会围绕三个方向展开。

### 🎮 游戏

不只是评测和攻略。我想聊游戏背后的设计逻辑、叙事手法，聊那些让我熬夜通关或中途弃坑的瞬间，聊游戏如何影响我们看待世界的方式。无论是 3A 大作还是独立小品，只要值得说，就会出现在这里。

### 🌍 现实世界

游戏之外，生活本身同样值得记录。可能是某个城市的街角、一本读到一半的书、一次失败的烹饪实验，或者对某个社会现象的碎碎念。现实世界的内容没有固定框架，唯一的标准是"真实"。

### 🛠️ 代码与工具

这是后来长出来的一块，也是目前更新最勤的部分。

- **[在线工具](/tools)**：图片压缩、格式转换、裁剪、加水印、转 ICO / Base64、像素画、SVG 优化、EXIF 查看与清除、PDF 合并拆分、二维码、开发工具，以及**我的世界坐标换算与数据包生成**、**CS2 准星 / 灵敏度 / 视角模型 / autoexec 生成器**。
- 所有工具都**只在你的浏览器里运行**：文件不会上传，没有账号，没有次数限制，关掉页面什么都不剩。
- **技术类文章**：记录这些工具是怎么做出来的——文件格式怎么手写、算法为什么这么选、哪些坑踩了两次。这些经验大多来自实际调试，而不是教程搬运。

如果你只想快速看看，可以直奔 [工具列表](/tools) 或 [博客归档](/blog/archive)。

## 这个站是怎么搭的？

一句话：**能静态就静态**。

- 用 [Docusaurus](https://docusaurus.io/) 构建，托管在 Cloudflare Pages
- 没有后端、没有数据库、没有账号系统；所有"智能"都发生在构建时或你的浏览器里
- 站点源码是开源的（MIT），文章内容采用 CC BY-NC-SA 4.0 许可，细节见[使用条款](/docs/info/terms)

这么做不是为了炫技，而是因为：**没有服务器，就没有能被拖库的服务器。**

## 这里会是什么样的节奏？

坦白说，我不想给自己设一个"每周必更"的 KPI。内容的质量比频率更重要。但我可以承诺：**每一篇发出来的东西，都是我认真想过、写过的。** 宁可慢一点，也不凑数。

## 最后

Connexion Collective 现在还很新，像一个刚搭好架子的房间。接下来的日子里，我会一点点往里添东西——文章、工具，或许还有一些没想清楚的尝试。

如果你愿意，欢迎常来看看。也可以把它加入你的阅读列表，或者在评论区留下一句话，让我知道你来过。

**连接，从这一篇开始。**
