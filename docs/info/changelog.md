# 网站更新日志

记录本站的每一次蜕变。

## 2026-10-26

**性能**

- 导航栏标志换成 WebP 格式，体积从 45 KB 降到 5 KB —— 每个页面都少下载 40 KB。
- 给图片服务与评论服务加上预连接，首屏图片和评论区出现得更快。
- 调整了图片的缓存方式：以后替换图片会同时换文件名，更新能立刻看到，不用再等缓存过期。

**可访问性与收录**

- 首页三个栏目标题改成正确的二级标题，不再从 h1 直接跳到 h3，屏幕阅读器的结构更清晰。
- 首页的装饰图标对屏幕阅读器隐藏，避免读出无意义的图形。
- 站点地图补充了每篇文章的更新时间，方便搜索引擎判断内容新旧。

## 2026-10-25

**内容**

- 新增文章《给博客找个放图的地方：把静态媒体搬上 Cloudflare R2》，英文版同步上线。

**图片**

- 文章配图改用 WebP：三张图合计从 177 KB 降到 63 KB，约减少 64%，画质无损。
- 站点标志做了一轮矢量优化（126 KB → 45 KB），并用逐像素比对确认肉眼看不出差别。
- 新增品牌分享卡片：链接被分享到社交平台时，显示站点自己的预览图，不再是模板默认图。
- 每篇文章支持单独设置分享图，分享出去能看出是哪一篇。

**交互**

- 博客列表每页显示 12 篇，不再出现「第二页只有两篇」的尴尬分页。
- 评论组件加载失败时，改为提供 GitHub 讨论区入口，不再是一片空白。
- 文章配图接入了独立的媒体服务，与站点本身分开加载。

**安全**

- 补全了站点的安全响应头，并收紧了页面可以加载的第三方资源范围。
