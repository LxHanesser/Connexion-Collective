# 网站更新日志

记录本站的每一次蜕变。

## 2026-11-03

**法务与隐私**

- 新增《隐私政策》：说明处理的信息类别、目的与法律依据、接收方类别、跨境传输、保留期，以及你在中国 PIPL、欧盟/英国 GDPR、美国加州 CCPA/CPRA 下的权利；同时覆盖巴西、加拿大、澳大利亚、日本、韩国、印度、新加坡、瑞士等主要法域。
- 重写《使用条款》：补充运营者与适用条件、消费者权利（含欧盟/英国、加州与中国的强制性保护）、责任限制、赔偿、版权与侵权通知流程；原「隐私」一节改为指向独立政策。
- 新增《广告与联盟推广说明》：当前不投放广告；若未来引入，将明确标注、保持内容独立、在 EEA/英国取得事先同意、为加州提供退出入口，并按 DSA 披露商业传播信息。
- 页脚新增「隐私政策」与「广告与联盟」入口。
- 为将来的广告同意预留了同意横幅：默认关闭，当前不显示、不写入任何浏览器存储。

**国际化**

- 英文站的「随便看看」不再跳到中文文章；英文路径下的 404 页面现在显示英文。
- 语言切换器中的「中文」改为「简体中文」；首页标语按语言显示（Connection starts here. / 连接，从这里开始。）。
- 英文文案统一为美式拼写，并润色「写在开始」页若干直译句。

**性能**

- 英文站的 JS/CSS 之前没有命中长缓存规则，现已补上：二次访问不再逐次回源校验。

**教程**

- 发布三篇教程：静态站点搜索、鼠标灵敏度换算、像素画降采样与中位切分调色板。

## 2026-11-02

**教程**

- 发布三篇教程：手写 SVG 优化器、图片裁剪与 EXIF 方向、Canvas 水印与批量导出。

**站点统计**

- 统计页数据更新至 11-02：累计 10 天、1,463 次浏览 / 471 次访问。

## 2026-11-01

**教程**

- 发布三篇教程：浏览器内图片压缩、从零实现二维码生成器、浏览器内 PDF 合并与拆分。每篇都给出可直接运行的完整代码，并附常见报错对照表。
- 新增 6 张手绘示意图（中英各一版），英文文章使用英文配图。

**教程**

## 2026-10-27

**页脚**

- 页脚加了一排可点击的安全徽章：SSL Labs A+、Security Headers A、HSTS、DNSSEC，以及「Hosted on Cloudflare」。每个都能点开查看对应的第三方实时报告。
- 徽章是本地 HTML/CSS 加同源 SVG，**不向任何第三方发请求**，也不会把访客 IP 交给外部服务。

**移动端**

- 手机菜单在文档页和博客页会先显示各自的目录；现在目录上方补了「首页 / 博客 / 在线工具」三个快捷入口，不用先点「回到主菜单」才能换区。
- 手机导航栏左上角的菜单按钮原本是 30px 的无底色三条线，不太像按钮；现在改为 44px 圆角按钮，触摸区域达标，深色模式单独调过对比度。

**博客**

- 列表分页改成带页码（1、2…），显示「第 X / Y 页」，到边界时箭头变灰。
- 文章底部上下篇改成卡片，补上发布日期，并显示「第 N / 共 M 篇」。
- 归档页重做：改成按年 / 月分组的单列列表，每行显示标签与阅读时长，顶部可以按标题或标签搜索；年份多于一个时提供跳转。

**整理**

- 移除了文档页与文章页底部的「编辑此页 / 编辑文章」链接 —— 那是给作者用的入口，访客点进去只会看到 GitHub 的编辑界面。

**条款与文档**

- 使用条款重写：明确开源许可（文章 **CC BY-NC-SA 4.0**、代码与源码 **MIT**）、补充隐私与数据处理说明、列出依赖的第三方服务，结构按国际通行惯例整理；仓库新增正式的 `LICENSE` 文件。
- 「写在开始」补上「代码与工具」一节，介绍在线工具与源码许可，并说明站点「能静态就静态」的搭建方式。
- 隐私章节修正：如实说明访问统计来自 **Cloudflare Web Analytics**（无 Cookie、无跨站追踪、无设备指纹），此前「不部署行为分析」的表述已经不准确。

## 2026-10-26

**性能**

- 导航栏标志换成 WebP 格式，体积从 45 KB 降到 5 KB —— 每个页面都少下载 40 KB。
- 给图片服务与评论服务加上预连接，首屏图片和评论区出现得更快。
- 调整了图片的缓存方式：以后替换图片会同时换文件名，更新能立刻看到，不用再等缓存过期。

**可访问性与收录**

- 首页三个栏目标题改成正确的二级标题，不再从 h1 直接跳到 h3，屏幕阅读器的结构更清晰。
- 首页的装饰图标对屏幕阅读器隐藏，避免读出无意义的图形。
- 站点地图补充了每篇文章的更新时间，方便搜索引擎判断内容新旧。

**工具**

- 在线工具分成两类：**现实工具**（图片、PDF、SVG、EXIF、开发工具）和 **游戏工具**（我的世界坐标换算、数据包生成器）。
- 新增 8 个工具：图片转 ICO、图片转 Base64、像素画转换、SVG 优化、EXIF 查看/清除、PDF 合并/拆分、我的世界坐标换算、我的世界数据包生成器。全部在浏览器里运行，文件不上传。
- 新增 4 个 CS2 工具：准星命令生成器（带实时预览）、灵敏度换算器（按 cm/360 在四款游戏间换算）、视角模型生成器、autoexec.cfg 生成器。
- 工具页顶部加了切换条，可以直接跳到同类工具；手机上是系统自带的下拉选择器，不用横向滑动。
- 工具列表支持搜索，输入「PDF」「坐标」这类关键词就能筛选。
- 导航栏的工具菜单改成按分类进入，不再随工具数量变长。
- 修掉一个视觉问题：在触摸设备上，点过的工具按钮会一直保留悬停颜色。
- 修掉导航栏工具菜单的误高亮：三个条目曾经在工具页上同时被标记为「当前页面」。

**内容**

- 新增五篇文章，记录这批工具的技术细节：手写 ICO 与 ZIP 编码器、SVG 优化的边界、像素画调色板、浏览器里的 PDF，以及一次移动端横向溢出的排查过程。英文版同步。
